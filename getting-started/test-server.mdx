# Local test server

A local server is disposable infrastructure. Keep it outside the source tree, accept the EULA deliberately, use a small test world, and automate only the safe parts of deployment.

## Create the environment

- Use a dedicated directory with the chosen server JAR.
- Set `eula=true` only after reading the EULA.
- Bind to localhost for private testing and use a non-production port.
- Keep production worlds, secrets, databases, and plugin data out of this directory.

## Fast edit-test loop

- Build the plugin with the project wrapper.
- Stop the server before replacing a JAR unless the platform explicitly supports a safe development reload.
- Start the server and inspect the entire enable log.
- Test both the success path and disable/shutdown cleanup.

## What to verify

- `/plugins` shows the plugin enabled.
- Commands are registered and permission failures are correct.
- Listeners do not fire twice after restarts.
- Data survives a full stop and start.
- No tasks, threads, sockets, or database pools remain after disable.

## Done check

Test the final JAR through a clean server start and stop. Treat warnings and shutdown failures as defects, not harmless development noise.
