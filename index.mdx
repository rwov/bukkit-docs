The Bukkit API is the standard Java interface for building Minecraft server plugins. Whether you want to add custom commands, respond to game events, manipulate the world, or create entirely new mechanics, Bukkit gives you the tools to do it cleanly and reliably on top of any SpigotMC-compatible server.

## How It Works

<Steps>
  <Step title="Add Bukkit as a dependency">
    Include the Bukkit artifact in your `pom.xml` or `build.gradle` to get access to the full API.
  </Step>
  <Step title="Create a JavaPlugin subclass">
    Extend `JavaPlugin` and override `onEnable()` to run your setup code when the server loads your plugin.
  </Step>
  <Step title="Describe your plugin in plugin.yml">
    Add a `plugin.yml` to your JAR's root with your plugin name, version, main class, commands, and permissions.
  </Step>
  <Step title="Drop the JAR into the server's plugins folder">
    The server discovers and loads your plugin automatically on next start or reload.
  </Step>
</Steps>

<Note>
  Bukkit targets **Java 17** and is distributed via the SpigotMC Maven repository. See the [Quickstart](/quickstart) for dependency setup.
</Note>
