# Build anything on a Minecraft server

A complete practical manual for Bukkit and Spigot—from your first `JavaPlugin` to custom menus, persistent multiplayer systems, minigames, databases, proxy networks, world generation, testing, and production performance.

## Target

This manual targets **Spigot-API 26.2-R0.1-SNAPSHOT**. Snapshot coordinates may move with Minecraft releases, so pin the artifact used by your server and verify exact signatures in the linked Javadocs.

<Warning>
  CraftBukkit classes, NMS classes, server implementations, and undocumented internals are not stable plugin API.
</Warning>
