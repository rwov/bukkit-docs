Items in Bukkit are represented by `ItemStack` — a combination of a `Material` type, a stack count, and an optional `ItemMeta` object that holds display names, lore, enchantments, and other rich data. The `Inventory` interface sits above all containers (player inventories, chests, custom GUI windows), giving you a uniform API for querying and mutating slot contents. This guide covers the full lifecycle of an item, from construction to giving it to a player, building custom GUI inventories, and responding to inventory click events.

## Creating an ItemStack

Construct an `ItemStack` with a `Material` and an optional amount. The default amount is `1` when you use the single-argument constructor.

```java CreateItems.java
import org.bukkit.Material;
import org.bukkit.inventory.ItemStack;

public class CreateItems {

    public ItemStack singleSword() {
        // ItemStack(Material) — amount defaults to 1
        return new ItemStack(Material.DIAMOND_SWORD);
    }

    public ItemStack stackOfStone() {
        // ItemStack(Material, int amount)
        return new ItemStack(Material.STONE, 64);
    }

    public ItemStack goldenApple() {
        return new ItemStack(Material.GOLDEN_APPLE, 1);
    }
}
```

<Note>
  Only use `ItemStack` with materials for which `Material.isItem()` returns `true`. Block-only materials like `Material.AIR` or `Material.WATER` cannot be represented as inventory items and will produce undefined behaviour.
</Note>

## Item Metadata

`ItemMeta` stores everything beyond the material type and amount: display name, lore lines, custom model data, and more. Retrieve a copy with `getItemMeta()`, mutate it, then write it back with `setItemMeta()`.

```java ItemMetaExample.java
import org.bukkit.ChatColor;
import org.bukkit.Material;
import org.bukkit.inventory.ItemStack;
import org.bukkit.inventory.meta.ItemMeta;
import java.util.Arrays;
import java.util.List;

public class ItemMetaExample {

    public ItemStack buildCustomSword() {
        ItemStack sword = new ItemStack(Material.DIAMOND_SWORD, 1);

        // Retrieve a mutable copy of the item's metadata
        ItemMeta meta = sword.getItemMeta();

        // Set the display name (supports ChatColor)
        meta.setDisplayName(ChatColor.AQUA + "" + ChatColor.BOLD + "Frostblade");

        // Set multi-line lore
        List<String> lore = Arrays.asList(
            ChatColor.GRAY + "Forged in the heart of a glacier.",
            ChatColor.BLUE + "Damage: " + ChatColor.WHITE + "+12"
        );
        meta.setLore(lore);

        // Write the modified metadata back onto the item
        sword.setItemMeta(meta);

        return sword;
    }
}
```

<Tip>
  `getItemMeta()` returns a **copy** of the metadata, not a live reference. You must call `setItemMeta(meta)` after making changes, or your edits will be lost.
</Tip>

## Enchantments

Add enchantments with `addEnchantment()`, which enforces the vanilla level bounds. Use `addUnsafeEnchantment()` to bypass those bounds and apply above-max levels.

```java EnchantmentExample.java
import org.bukkit.Material;
import org.bukkit.enchantments.Enchantment;
import org.bukkit.inventory.ItemStack;

public class EnchantmentExample {

    public ItemStack sharpSword() {
        ItemStack sword = new ItemStack(Material.DIAMOND_SWORD, 1);

        // addEnchantment enforces level bounds (Sharpness max is 5)
        sword.addEnchantment(Enchantment.SHARPNESS, 5);

        return sword;
    }

    public ItemStack godSword() {
        ItemStack sword = new ItemStack(Material.NETHERITE_SWORD, 1);

        // addUnsafeEnchantment bypasses level restrictions
        sword.addUnsafeEnchantment(Enchantment.SHARPNESS, 100);
        sword.addUnsafeEnchantment(Enchantment.UNBREAKING, 10);
        sword.addUnsafeEnchantment(Enchantment.LOOTING, 10);

        return sword;
    }

    public boolean hasSharpness(ItemStack item) {
        return item.containsEnchantment(Enchantment.SHARPNESS);
    }

    public int sharpnessLevel(ItemStack item) {
        return item.getEnchantmentLevel(Enchantment.SHARPNESS);
    }
}
```

<Warning>
  `addUnsafeEnchantment()` can produce items that look odd or behave unexpectedly on vanilla clients. Use it intentionally — for example when building custom boss drops — rather than as a default.
</Warning>

## Player Inventory

`player.getInventory()` returns the player's `PlayerInventory`. You can add items, remove them by material, check for specific contents, and equip armour slots directly.

```java PlayerInventoryExample.java
import org.bukkit.Material;
import org.bukkit.entity.Player;
import org.bukkit.inventory.ItemStack;
import org.bukkit.inventory.PlayerInventory;
import java.util.Map;

public class PlayerInventoryExample {

    public void giveItem(Player player, ItemStack item) {
        PlayerInventory inv = player.getInventory();

        // addItem returns a map of items that couldn't fit; drop leftovers
        Map<Integer, ItemStack> leftover = inv.addItem(item);
        leftover.values().forEach(stack ->
            player.getWorld().dropItemNaturally(player.getLocation(), stack)
        );
    }

    public void removeStone(Player player) {
        // Removes all stacks of STONE from the player's inventory
        player.getInventory().remove(Material.STONE);
    }

    public boolean hasItem(Player player, Material material) {
        return player.getInventory().contains(material);
    }

    public void equipDiamondArmour(Player player) {
        PlayerInventory inv = player.getInventory();
        inv.setHelmet(new ItemStack(Material.DIAMOND_HELMET));
        inv.setChestplate(new ItemStack(Material.DIAMOND_CHESTPLATE));
        inv.setLeggings(new ItemStack(Material.DIAMOND_LEGGINGS));
        inv.setBoots(new ItemStack(Material.DIAMOND_BOOTS));
    }
}
```

## Custom Inventories

You can create a custom `Inventory` with `Bukkit.createInventory()` and open it for players. The size must be a multiple of 9 (up to 54 slots for a double-chest). Passing `null` as the owner creates an ownerless inventory.

```java CustomInventoryExample.java
import org.bukkit.Bukkit;
import org.bukkit.Material;
import org.bukkit.entity.Player;
import org.bukkit.inventory.Inventory;
import org.bukkit.inventory.ItemStack;

public class CustomInventoryExample {

    public void openShopGui(Player player) {
        // createInventory(owner, size, title)
        Inventory gui = Bukkit.createInventory(null, 27, "§6Item Shop");

        // Populate slots with items
        gui.setItem(10, new ItemStack(Material.DIAMOND_SWORD));
        gui.setItem(12, new ItemStack(Material.BOW));
        gui.setItem(14, new ItemStack(Material.GOLDEN_APPLE, 8));
        gui.setItem(16, new ItemStack(Material.ENDER_PEARL, 4));

        // Open the GUI for the player
        player.openInventory(gui);
    }
}
```

<Note>
  Slot indexes count left-to-right, top-to-bottom, starting at `0`. A 27-slot inventory (3 rows × 9 columns) has slots `0–26`. Plan your layout on paper or use a grid diagram to avoid off-by-one errors.
</Note>

## Handling Inventory Clicks

Listen to `InventoryClickEvent` to respond when a player clicks a slot inside any open inventory. Always cancel the event in custom GUIs to prevent players from picking up or rearranging your GUI items.

```java InventoryClickListener.java
import org.bukkit.Material;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.inventory.InventoryClickEvent;
import org.bukkit.inventory.ItemStack;

public class InventoryClickListener implements Listener {

    @EventHandler
    public void onInventoryClick(InventoryClickEvent event) {
        // Only handle our custom GUI, identified by its title
        String title = event.getView().getTitle();
        if (!title.equals("§6Item Shop")) return;

        // Always cancel clicks inside our GUI
        event.setCancelled(true);

        // Ignore clicks on empty slots
        ItemStack clicked = event.getCurrentItem();
        if (clicked == null || clicked.getType() == Material.AIR) return;

        Player player = (Player) event.getWhoClicked();
        int slot      = event.getSlot();

        switch (slot) {
            case 10 -> player.sendMessage("You selected: Diamond Sword");
            case 12 -> player.sendMessage("You selected: Bow");
            case 14 -> player.sendMessage("You selected: Golden Apple");
            case 16 -> player.sendMessage("You selected: Ender Pearl");
            default -> {}
        }
    }
}
```

<Warning>
  `InventoryClickEvent` fires for every inventory the player has open, including their own player inventory. Always check the inventory title or a custom identifier before acting on a click, otherwise your listener will interfere with normal gameplay.
</Warning>

## Full Example: Custom GUI Chest with Clickable Items

The following example brings everything together into a self-contained plugin component: a GUI inventory with named items, a click listener that handles purchases, and registration of the listener.

<CodeGroup>

```java ShopGui.java
import org.bukkit.Bukkit;
import org.bukkit.ChatColor;
import org.bukkit.Material;
import org.bukkit.entity.Player;
import org.bukkit.inventory.Inventory;
import org.bukkit.inventory.ItemStack;
import org.bukkit.inventory.meta.ItemMeta;
import java.util.List;

public class ShopGui {

    private static final String GUI_TITLE = ChatColor.GOLD + "Item Shop";

    public static void open(Player player) {
        Inventory gui = Bukkit.createInventory(null, 27, GUI_TITLE);

        gui.setItem(11, buildItem(Material.DIAMOND_SWORD,
            ChatColor.AQUA + "Diamond Sword",
            List.of(ChatColor.GRAY + "Cost: 50 coins")));

        gui.setItem(13, buildItem(Material.GOLDEN_APPLE,
            ChatColor.YELLOW + "Golden Apple",
            List.of(ChatColor.GRAY + "Cost: 10 coins")));

        gui.setItem(15, buildItem(Material.ENDER_PEARL,
            ChatColor.GREEN + "Ender Pearl",
            List.of(ChatColor.GRAY + "Cost: 5 coins")));

        player.openInventory(gui);
    }

    private static ItemStack buildItem(Material mat, String name, List<String> lore) {
        ItemStack stack = new ItemStack(mat, 1);
        ItemMeta meta   = stack.getItemMeta();
        meta.setDisplayName(name);
        meta.setLore(lore);
        stack.setItemMeta(meta);
        return stack;
    }

    public static String guiTitle() {
        return GUI_TITLE;
    }
}
```

```java ShopClickListener.java
import org.bukkit.ChatColor;
import org.bukkit.Material;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.inventory.InventoryClickEvent;
import org.bukkit.inventory.ItemStack;

public class ShopClickListener implements Listener {

    @EventHandler
    public void onClick(InventoryClickEvent event) {
        if (!event.getView().getTitle().equals(ShopGui.guiTitle())) return;

        // Prevent item movement in the GUI
        event.setCancelled(true);

        ItemStack clicked = event.getCurrentItem();
        if (clicked == null || clicked.getType() == Material.AIR) return;

        Player buyer = (Player) event.getWhoClicked();
        int slot     = event.getSlot();

        switch (slot) {
            case 11 -> {
                buyer.getInventory().addItem(new ItemStack(Material.DIAMOND_SWORD));
                buyer.sendMessage(ChatColor.GREEN + "You bought a Diamond Sword!");
            }
            case 13 -> {
                buyer.getInventory().addItem(new ItemStack(Material.GOLDEN_APPLE));
                buyer.sendMessage(ChatColor.GREEN + "You bought a Golden Apple!");
            }
            case 15 -> {
                buyer.getInventory().addItem(new ItemStack(Material.ENDER_PEARL));
                buyer.sendMessage(ChatColor.GREEN + "You bought an Ender Pearl!");
            }
        }
    }
}
```

```java MyPlugin.java
import org.bukkit.plugin.java.JavaPlugin;

public class MyPlugin extends JavaPlugin {

    @Override
    public void onEnable() {
        // Register the shop click listener
        getServer().getPluginManager().registerEvents(
            new ShopClickListener(), this
        );

        // Register a command to open the shop
        getCommand("shop").setExecutor((sender, cmd, label, args) -> {
            if (sender instanceof org.bukkit.entity.Player player) {
                ShopGui.open(player);
            }
            return true;
        });
    }
}
```

</CodeGroup>

<Tip>
  For larger, more complex GUIs consider building a reusable `GuiManager` class that maps inventory titles (or `InventoryHolder` implementations) to click handlers. This avoids long `switch` statements and keeps your listener code clean as your GUI count grows.
</Tip>
